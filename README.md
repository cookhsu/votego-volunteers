# VoteGo 志工管理系統｜完整產品與開發規格

## 交付範圍與啟動

本專案是 VoteGo 的獨立志工工作區。這次交付可啟動的本機版本，包含實際 SQLite 儲存、三種示範帳號及志工行政的核心流程。請使用 Node.js 23.11 或相容且支援 `node:sqlite` 的版本。無須安裝 npm 套件。

```powershell
node server.mjs
```

開啟 http://127.0.0.1:4175/ 並選擇示範角色。測試請執行 `node test.mjs`。預設在專案目錄建立 `volunteers.sqlite`，伺服器只監聽本機。所有種子資料均為示範。正式身分驗證、跨團隊資料隔離、公開報名及部署列入後續工作。請勿以示範帳號或測試環境保存真實志工個資。

## 介面與資訊架構

Vercel 建置執行 `node build.mjs` 並發布 `public/`。正式環境使用 `api/workspace.mjs` 和專用 PostgreSQL，需設定伺服器端的 `DATABASE_URL`。初次上線在 Vercel 將 `VOTEGO_SETUP_CODE` 設為隨機的敏感環境變數，使用網站的設定頁建立第一個管理員。建立成功後設定路徑會自動關閉。預覽環境仍可使用由分頁 sessionStorage 隔離的假資料，SQLite 伺服器保留供本機使用。

| 畫面 | 桌機 | 手機與鍵盤操作 |
|---|---|---|
| 首頁總覽 | 深藍側欄、四張指標卡、活動、組別分布、待辦和最新名單 | 手機使用選單、雙欄指標與單欄內容。鍵盤可跳到主內容 |
| 名單與報名審核 | 可搜尋姓名與組別，顯示待審與核准狀態 | 表格可水平捲動。新增表單使用原生對話框，支援 Esc 關閉 |
| 活動與班次 | 活動時間、地點、已指派志工及防重疊規則 | 志工只看到自己的活動與班次。表單為可觸控的單欄 |
| 任務與物資 | 到期日、完成狀態、庫存數量 | 以文字呈現狀態，避免只靠色彩辨識 |
| 報表與稽核 | 依組別與狀態統計，管理員可看最近操作 | 圖表保留文字數字。各角色使用相同欄位名稱及流程 |

## 完整版功能流程

1. **報名與審核。** 正式版提供公開報名表，選填聯絡偏好、可服務時段及組別，送出前顯示使用目的。審核可補件、核准、婉拒或撤回，並保存操作歷程。核准後發送一次性啟用邀請。本機版已能代登報名、核准或退回。
2. **活動與排班。** 建立活動後設定各時段、地點、人數上限和組別需求。依志工可服務時段排班，提交前查重疊與重覆指派。正式版提供候補、志工確認、請假、換班與簽到退。本機版已能建活動及指派已核准志工，並擋下重疊與重複指派。
3. **任務。** 正式版依活動或組別指派負責人，使用待辦、進行中、已完成和取消狀態，追蹤期限。本機版可新增任務、完成與重新開啟。
4. **物資。** 正式版以入庫、領用、歸還、報廢及盤點等異動計算庫存，庫存不得低於零。本機版管理員可調整現有數量並留下稽核。
5. **報表。** 正式版提供組別人力、出勤時數、缺口、任務結案率和物資消耗。匯出預設只含統計，含個資的匯出另設權限並記錄用途與操作者。
6. **通知。** 正式版提供站內通知與可選的電子郵件。由使用者決定接收偏好，背景工作需可重試並防止重複發送。
7. **例外流程。** 重複提交需採用請求識別碼，並行排班只能成功一次，編輯時提示資料已更新。取消活動需保留歷史、解除尚未開始的安排並通知受影響志工。

## 資料庫

本機版實際結構見 `schema.sql`。正式版建議使用 PostgreSQL，採版本化遷移。時間使用帶時區欄位，介面預設使用 Asia/Taipei。

| 資料表 | 資料與規則 |
|---|---|
| organizations、teams | 組織與組別。業務資料都帶組織 ID，組別名稱在同組織內唯一 |
| users、memberships | 登入身分、成員所屬組織、角色及組別。用複合外鍵限制跨組織引用 |
| volunteer_profiles、applications | 志工檔案與報名歷程。個資與業務欄位分離，狀態轉移與審核人可追溯 |
| availabilities | 志工可支援起迄時間、組別偏好 |
| events、shift_slots、assignments | 活動、各班次、志工指派與回覆。班次人數與同人時間重疊檢查在交易內執行 |
| attendance | 指派、簽到退、工時及原因。每個指派用唯一鍵防止重複簽到 |
| tasks | 活動或組別、負責人、期限與狀態 |
| inventory_items、inventory_movements | 物資主檔、庫位與異動。以異動帳記錄增減與操作者 |
| notifications、outbox | 通知內容、接收者及可重試發送狀態 |
| audit_logs | 操作者、時間、資源及動作。稽核內容遮罩聯絡資訊與敏感欄位 |

正式版索引至少涵蓋組織／狀態、組織／活動日期、志工／班次時間、物資／異動時間。軟停用已排班志工，以保留既有歷史。

## 權限

| 動作 | 系統管理員 | 團隊協調員 | 志工 |
|---|---|---|---|
| 建立組織、帳號、角色與組別 | 組織內管理 |  |  |
| 報名與審核 | 組織內 | 指定組別 | 僅本人報名與補件 |
| 活動及排班 | 組織內 | 指定活動或組別 | 僅本人班次及回覆 |
| 任務 | 組織內 | 指定組別 | 僅指派給本人 |
| 庫存與稽核 | 管理庫存、查看稽核 | 指定物資查詢與領用 | 僅本人領用紀錄 |
| 報表與匯出 | 組織統計，敏感匯出另授權 | 指定組別統計 | 僅本人服務紀錄 |

上表為正式版目標。本機版採單一工作區，協調員可操作工作區內的報名、活動、排班與任務，庫存寫入與稽核讀取限管理員，志工 API 僅回傳本人與本人班次。正式版將由後端與資料層同時檢查範圍，並使用正式登入、工作階段撤銷、HTTPS、安全 Cookie、最小資料蒐集、保留期限及備份還原演練。

## Codex 開發方案

| 階段 | 工作 | 驗收 |
|---|---|---|
| 起始版 | 依參考圖建立響應式儀表板，加入本機資料庫與驗證，跑通報名至排班 | 三角色可試用，可重現並擋下排班衝突與越權 |
| 資料與身分 | 建立正式資料庫遷移、登入供應商與組織／組別隔離 | 測試帳號無法跨組存取，撤銷後現有工作階段失效 |
| 報名與班次 | 公開報名、邀請、候補、班次容量、確認與請假 | 重複提交及並行操作無重複名單或超額排班 |
| 日常營運 | 出勤、物資異動、通知、報表及匯出 | 報表可對帳，通知可重試，匯出權限有稽核 |
| 上線驗收 | 建獨立預覽環境，以假資料驗證桌機與手機，加入備份及回滾 | 測試登入與重設、越權、並行、鍵盤、手機版及備份還原 |

每階段以短分支或獨立 PR 交付。給 Codex 的工作單應列出要改的流程、角色、資料表、測試情境與驗收條件。變更資料庫時附遷移與回滾方案，畫面變更以桌機／手機截圖核對，權限變更要同時測 API 成功與拒絕。正式環境在預覽驗收及明確部署授權後再上線。
